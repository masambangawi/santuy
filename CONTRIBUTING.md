# Contributing to Skill Santuy 🤝

Thank you for your interest in contributing to **Skill Santuy**! We welcome improvements to prompt wording, documentation, test scenarios, harness integrations, and cultural humor formulas.

---

## Code of Conduct

All contributors are expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md). While the skill itself embraces satirical comedic elements, contributor interactions on GitHub (issues, PRs, discussions) must remain courteous, inclusive, and professional.

---

## How Can I Contribute?

### 1. Suggesting New Slang / Sentence Formulas
Have an iconic Indonesian internet meme or sentence pattern that would fit naturally?
- Open an issue using our [Formula Suggestion Form](.github/ISSUE_TEMPLATE/formula-suggestion.yml).
- Explain the cultural context, provide example dialogues, and verify that it adheres to our safety boundaries.

### 2. Reporting Harness Compatibility
Tested Skill Santuy on a new tool or harness (e.g., Aider, Roo Code, Cline)?
- Submit an issue using the [Harness Compatibility Form](.github/ISSUE_TEMPLATE/harness-compatibility.yml).
- Detail where skills are located in that harness and any specific quirks.

### 3. Submitting Pull Requests
- Fork the repository and create a new feature branch (`git checkout -b feature/my-new-formula`).
- Ensure your changes follow the [Agent Skills Specification](https://agentskills.io/specification).
- Double check that the **Golden Rule** is preserved: slang belongs exclusively in chat examples and reference docs, never in production code templates.
- Fill out the provided [Pull Request Template](.github/pull_request_template.md).

---

## Contributor Attribution

We embrace open-source attribution! When you submit a pull request, your git commit author identity will remain intact. Maintainers review and merge community contributions directly through standard GitHub PR workflows.
